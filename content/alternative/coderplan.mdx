## OpenAI-Compatible LLM API Gateway

CoderPlan provides a unified, OpenAI-compatible API gateway that lets developers access Claude, GPT, and other LLM models through a single endpoint. Designed specifically for developers using AI coding tools like Claude Code, Cursor, and Windsurf.

### Key Features

- **OpenAI-Compatible API**: Drop-in replacement for OpenAI API endpoints
- **Multi-Model Support**: Access Claude, GPT, Gemini, and more through one API key
- **Pay-Per-Use**: Only pay for what you use, with a generous free tier
- **Low Latency**: Global endpoints optimized for developer workflows
- **Automatic Failover**: Seamless switching between models if one is unavailable
- **Free Tier**: Get started without a credit card

### Perfect For

- Developers using Claude Code or Cursor
- Teams needing reliable API access to multiple LLM providers
- Projects that want OpenAI-compatible API without vendor lock-in
- Anyone looking for an affordable alternative to direct API access
