## Review, Features

### Agent-readiness scores for software tools

Agent Native Registry scores 1,900+ software tools on how well they work with AI agents. Each tool is evaluated on a 33-point pass/fail checklist across five dimensions: Discovery, Auth, Pricing, Agent Tooling, and Reliability.

Scores are fully auditable — every check is visible so you can see exactly why a tool scored the way it did. A free MCP server lets AI agents query the registry directly.

Built for developers and teams evaluating tools for agent workflows, multi-step automation, and MCP integrations.

## Pricing

Free to browse and use. MCP server access included at no cost.
